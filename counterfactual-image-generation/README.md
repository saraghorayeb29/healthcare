# Counterfactual image generation

I co-authored a method that adapts pretrained image models for controlled X-ray edits with limited training data.

Paper: *Generating Chest X-Ray Counterfactuals by Specialising Foundation Image Models*.

https://arxiv.org/abs/2609.24879

This entry links to the paper only. No counterfactual project source code or model files are published here.
