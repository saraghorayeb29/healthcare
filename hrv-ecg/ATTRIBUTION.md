# Group coursework attribution

The source in `legacy/` is Group 18 coursework from Imperial College London, 2022.
Sara Ghorayeb contributed alongside other group members. Attribution belongs to the group, not Sara alone.

Upstream repository: https://github.com/molbioeng/Molecool

Pinned upstream commit: `7ce6eea28b7c75a120c20a5d2278239a8bee8078`.

This publication includes all 11 top-level notebooks and all 10 `misc/*.py` source modules at that commit.
The original Python modules are unchanged.

Notebook publication changes remove saved outputs, execution counts, attachments, and metadata.
Private machine paths become relative dataset paths. Individual names become generic group references.
Original record identifiers become consistent generic placeholders. Historical cohort-count text is omitted.
Two syntax-only corrections indent a function docstring and align an `except` clause.
Notebook algorithms and original source citations are otherwise retained.

Several filter docstrings cite code from https://github.com/paulvangentcom/heartrate_analysis_python/tree/0005e98618d8fc3378c03ab0a434b5d9012b1221.
Those citations remain in the original modules and notebooks. Their authors retain their rights.

Sara confirmed authorization to republish the group code.
That confirmation is not a blanket grant to relicense every contributor's work.
The upstream repository has no code license. Its `database/LICENSE.txt` concerns data, not the source code.
The root MIT license therefore excludes every file in `legacy/`, including the sanitation and syntax-only changes.
